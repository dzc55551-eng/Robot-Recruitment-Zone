## 📌 仓库介绍
本仓库集中展示机器人赛道在招岗位，全部为猎头代招，对接成都本地机器人企业。
岗位方向包含：
- SLAM / 多传感器融合定位算法
- 机器人感知、障碍物检测、多传感器标定
- 机器人路径规划、全覆盖导航、运动控制
- 视觉深度学习、目标检测、语义分割、模型部署
- 机器人整机结构设计
- 机器人主板、电源、驱动硬件开发

适合拥有移动机器人、服务机器人、扫地机器人、自动驾驶相关落地项目经验的工程师。
